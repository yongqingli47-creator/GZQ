# Manuscript Polish Skill

Use this skill when the task is to improve scholarly writing without weakening precision.

## Revision Priorities

1. Preserve the author's substantive claim while tightening logic.
2. Remove vague evaluative language unless evidence supports it.
3. Keep contribution statements specific and verifiable.
4. Improve transitions so each section answers an identifiable question.
5. Where a paragraph is weak, provide a revised version and explain the change briefly.

## Referee Response Standard

- Restate the reviewer concern fairly.
- Acknowledge valid limits directly.
- Explain the change made or why a requested change is not methodologically appropriate.
- Keep tone professional and non-defensive.

## Output Shape

- Diagnosis
- Proposed rewrite
- Why this is stronger

## Procedure

1. Identify the exact claim the passage needs to carry.
2. Diagnose whether the main weakness is logic, evidence alignment, structure, or expression.
3. Rewrite only as much as needed to fix the highest-value problems.
4. Keep contribution and causal language aligned with the actual evidence.
5. Return a brief diagnosis that the author can use for further revision.

## Automated Review Limits

- Simulated peer review can generate objections and alternative readings; it is an internal stress test, not evidence of actual reviewer agreement or a substitute for expert review.
- Resolve each generated comment against the manuscript, data, code, and cited sources. Record whether it was accepted, revised, or rejected and why; do not cite simulated feedback as an external authority.
- Use review simulation after factual and numerical claims have a traceable source. Do not let an agent rewrite results or references without source checks.
