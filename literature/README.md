# Literature Workspace

This folder holds repository-local literature resources.

## Layout

- `bib/`: Better BibTeX auto-export target.
- `metadata/`: Zotero API snapshots generated by `scripts/zotero_sync.py`.

## Expected Files

- `bib/library.bib`: the main Better BibTeX export.
- `metadata/zotero_items.json`: structured metadata and abstracts.
- `metadata/zotero_items.md`: quick human-readable digest.

Refresh the metadata snapshot after major Zotero updates so repository prompts and skills work from current sources.
